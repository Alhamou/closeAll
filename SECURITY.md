# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

Use GitHub private vulnerability reporting on [Alhamou/closeAll](https://github.com/Alhamou/closeAll/security/advisories/new). Include what you can do, which macOS version you used, and the smallest steps that show the problem.

closeAll force-quits other applications on purpose. A report about that intended behavior, with no extra impact, is a product issue rather than a vulnerability. Reports about quitting Finder, quitting processes outside the documented set, or escaping the keep-list are in scope.

We will acknowledge a report within 7 days and follow up with a fix or an explanation.
